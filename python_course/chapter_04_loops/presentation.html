Chapter 4

Repetition with Loops

Making Programs Work Smarter, Not Harder

Why Do We Need Loops? 🔄

Imagine you need to print "Hello" 100 times...

Without Loops (Bad!) ❌

print("Hello")
print("Hello")
print("Hello")
... 97 more times ...

With Loops (Good!) ✅

for i in range(100):
print("Hello")

Loops let us repeat code efficiently!

While Loops: Repeat While True ⏳

A while loop repeats as long as a condition is True

Syntax:

while condition:
# code to repeat

Example: Count to 5

count = 1
while count <= 5:
print(count)
count = count + 1

Output:

1
2
3
4
5

Important: Don't forget to update the counter, or the loop runs forever!

While Loops with Counters 🔢

Pattern for Counter Loops:

# 1. Initialize counter
counter = 0
# 2. Check condition
while counter < 10:
# 3. Do something
print("Loop iteration:", counter)
# 4. Update counter
counter += 1

Countdown

countdown = 10
while countdown > 0:
print(countdown)
countdown -= 1
print("Liftoff!")

Sum Numbers

num = 1
total = 0
while num <= 5:
total += num
num += 1
print(total) # 15

While Loops with Conditions 🎯

While loops can use any condition, not just counters

User Input Loop

password = ""
while password != "python123":
password = input("Enter password: ")
print("Access granted!")

Keep Doubling Until Large

number = 1
while number < 100:
print(number)
number = number * 2
# Prints: 1, 2, 4, 8, 16, 32, 64

For Loops: Iterate Through Items 🔁

For loops iterate through a sequence of items

Syntax:

for item in sequence:
# code to repeat for each item

Example: Loop Through a String

word = "Python"
for letter in word:
print(letter)

Output:

P
y
t
h
o
n

Each iteration: letter gets the next character from the string

The range() Function 📊

range() generates a sequence of numbers for loops

1. range(stop) - Single Parameter

for i in range(5):
print(i)
# Output: 0, 1, 2, 3, 4 (stops before 5)

2. range(start, stop) - Two Parameters

for i in range(3, 8):
print(i)
# Output: 3, 4, 5, 6, 7 (starts at 3, stops before 8)

3. range(start, stop, step) - Three Parameters

for i in range(0, 10, 2):
print(i)
# Output: 0, 2, 4, 6, 8 (count by 2s)

range() Patterns 🎨

Count by 10s

for i in range(0, 100, 10):
print(i)
# 0, 10, 20, ... 90

Countdown

for i in range(10, 0, -1):
print(i)
# 10, 9, 8, ... 1

Odd Numbers

for i in range(1, 10, 2):
print(i)
# 1, 3, 5, 7, 9

Repeat N Times

for i in range(5):
print("Hello")
# Prints Hello 5 times

Remember: range(stop) starts at 0 and stops BEFORE stop

Break Statement: Exit Early 🛑

The break statement immediately exits the loop

Example: Find First Even Number

numbers = [1, 3, 7, 8, 9, 12]
for num in numbers:
if num % 2 == 0:
print("Found even number:", num)
break # Exit loop immediately
# Output: Found even number: 8

Example: Guessing Game

secret = 7
while True:
guess = int(input("Guess a number: "))
if guess == secret:
print("Correct!")
break # Exit when correct
print("Try again!")

Continue Statement: Skip Iteration ⏭️

The continue statement skips the rest of the current iteration

Example: Print Only Odd Numbers

for i in range(1, 11):
if i % 2 == 0:
continue # Skip even numbers
print(i)
# Output: 1, 3, 5, 7, 9

Example: Skip Negative Numbers

numbers = [-2, 5, -1, 8, -3, 10]
for num in numbers:
if num < 0:
continue # Skip negatives
print(num)
# Output: 5, 8, 10

break exits the loop completely | continue skips to next iteration

Nested Loops: Loops Inside Loops 🔄🔄

You can put loops inside other loops!

Example: Multiplication Table

for i in range(1, 4):
for j in range(1, 4):
print(f"{i} x {j} = {i * j}")
print() # Blank line after each row

Pattern: Rectangle

for row in range(3):
for col in range(5):
print("*", end="")
print() # New line

Output:

*****
*****
*****

Real-World Applications 🌍

Sum of Numbers

total = 0
for i in range(1, 101):
total += i
print("Sum of 1 to 100:", total) # 5050

Average Calculator

total = 0
count = 5
for i in range(count):
num = float(input(f"Enter number {i+1}: "))
total += num
average = total / count
print(f"Average: {average}")

Factorial Calculator

n = 5
factorial = 1
for i in range(1, n + 1):
factorial *= i
print(f"{n}! = {factorial}") # 5! = 120

Which Loop Should I Use? 🤔

Use FOR loops when:

  • ✅ You know how many times to repeat
  • ✅ You're iterating through a sequence (string, list, range)
  • ✅ You need a counter variable

Use WHILE loops when:

  • ✅ You don't know how many times to repeat
  • ✅ You're waiting for a condition to change
  • ✅ You're validating user input

Pro Tip: If you can use a for loop, it's usually better (clearer and safer)!

Common Mistakes to Avoid ⚠️

Infinite Loop (Never Stops!)

count = 1
while count < 10:
print(count)
# Forgot to increment! Will loop forever!

Off-by-One Error

# Want numbers 1 to 10, but get 0 to 9
for i in range(10):
print(i) # Prints 0-9, not 1-10!
# Fix: use range(1, 11)

Forgetting Indentation

for i in range(5):
print(i) # IndentationError!
# Must be indented to be inside the loop
