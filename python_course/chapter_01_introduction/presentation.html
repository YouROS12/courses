Variables: Storing Information 📦

Think of a variable as a labeled box where you can store information

Example:

name = "Sarah"
age = 20
height = 1.65

Box Label

name

Contains: "Sarah"

Box Label

age

Box Label

height

Data Types: Numbers 🔢

Integers (int)

Whole numbers without decimals

students = 30
temperature = -5
year = 2024

Floats (float)

Numbers with decimal points

price = 19.99
pi = 3.14159
grade = 85.5

Data Types: Text (Strings) 📝

Strings are text enclosed in quotes - single or double

message = "Hello, World!"
city = 'Paris'
course = "Python Programming"

Important: Both 'single' and "double" quotes work, but be consistent!

✓ Correct

"Hello"

✗ Wrong

"Hello'

Displaying Output: print() 🖨️

The print() function displays information on the screen

Examples:

# Print text
print("Hello, Python!")
# Print numbers
print(42)
# Print variables
name = "Ahmed"
print(name)
# Print multiple things
print("My age is", 25)

Let's Build Something! 🔨

A Simple Calculator

# Store numbers in variables
num1 = 10
num2 = 5
# Perform calculations
sum_result = num1 + num2
difference = num1 - num2
product = num1 * num2
# Display results
print("Sum:", sum_result)
print("Difference:", difference)
print("Product:", product)
