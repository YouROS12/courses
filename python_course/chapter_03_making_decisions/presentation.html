Boolean Values: True or False ✓✗

Boolean is a data type with only two possible values

True

Yes, Correct, 1

False

No, Incorrect, 0

Examples:

is_sunny = True
is_raining = False
has_permission = True

Comparison Operators ⚖️

== (Equal to)

5 == 5 → True
5 == 3 → False

!= (Not equal to)

5 != 3 → True
5 != 5 → False

> (Greater than)

10 > 5 → True
3 > 7 → False

< (Less than)

3 < 7 → True
10 < 5 → False

>= (Greater or equal)

5 >= 5 → True
3 >= 7 → False

<= (Less or equal)

5 <= 5 → True
10 <= 5 → False

⚠️ Important: Use == for comparison, not = (which is for assignment)

The if Statement 🚦

Execute code only if a condition is True

Syntax:

if condition:
# code to execute if True

Example:

age = 20
if age >= 18:
print("You are an adult")

Key Point: The colon (:) and indentation are required!

The if-else Statement 🔀

Do one thing if True, something else if False

Syntax:

if condition:
# code if True
else:
# code if False

Example:

temperature = 25
if temperature > 30:
print("It's hot!")
else:
print("It's nice!")

The if-elif-else Statement 🔀🔀

Check multiple conditions in order

Syntax:

if condition1:
# code if condition1 is True
elif condition2:
# code if condition2 is True
else:
# code if all conditions are False

Example: Grade System

score = 85
if score >= 90:
print("Grade: A")
elif score >= 80:
print("Grade: B")
elif score >= 70:
print("Grade: C")
else:
print("Grade: F")

Logical Operators 🔗

Combine multiple conditions

and (Both must be True)

True and True → True
True and False → False
False and False → False
Example: age >= 18 and has_license == True

or (At least one must be True)

True or True → True
True or False → True
False or False → False
Example: is_weekend or is_holiday

not (Reverses the value)

not True → False
not False → True

Real-World Example 🎫

Movie Ticket Pricing

age = int(input("Enter your age: "))
is_student = input("Are you a student? (yes/no): ")
if age < 12:
price = 5
print("Child ticket: $5")
elif age >= 65:
price = 7
print("Senior ticket: $7")
elif is_student == "yes":
price = 8
print("Student ticket: $8")
else:
price = 12
print("Regular ticket: $12")
