Avoid Repetition

Organization

Reusability

DRY Principle: Don't Repeat Yourself - write code once and reuse it!

Defining Functions ✨

Use the def keyword to create a function

Basic Syntax:

def function_name():
# Code to execute
print("Hello from the function!")

Simple Example:

def greet():
print("Hello, World!")
print("Welcome to Python!")
# Call the function
greet()

Parameters and Arguments 📥

Parameter

Variable in the function definition

Argument

Actual value passed when calling

Example:

def greet(name):
print(f"Hello, {name}!")
# Calling with different arguments
greet("Alice") # Hello, Alice!
greet("Bob") # Hello, Bob!

Multiple Parameters:

def add(a, b):
result = a + b
print(f"{a} + {b} = {result}")

Return Values 📤

Functions can return values back to the caller

Without Return:

def add_no_return(a, b):
print(a + b) # Just prints
add_no_return(5, 3) # Prints: 8

With Return:

def add_with_return(a, b):
return a + b # Returns the value
result = add_with_return(5, 3)
print(result) # Prints: 8
print(result * 2) # Can use the value! Prints: 16

Default Parameters 🎯

Set default values for parameters - optional arguments!

Example:

def greet(name, greeting="Hello"):
print(f"{greeting}, {name}!")
# Using default greeting
greet("Alice") # Hello, Alice!
# Custom greeting
greet("Bob", "Hi") # Hi, Bob!

Multiple Defaults:

def order_coffee(size="medium", milk=True, sugar=1):
print(f"{size} coffee, milk: {milk}, sugar: {sugar}")
order_coffee() # Uses all defaults
order_coffee("large", milk=False) # Customize some

Multiple Return Values 🎁

Python functions can return multiple values at once!

Returning Multiple Values:

def get_stats(numbers):
total = sum(numbers)
average = total / len(numbers)
return total, average
# Unpack the returned values
sum_val, avg_val = get_stats([10, 20, 30])
print(f"Sum: {sum_val}, Average: {avg_val}")

Note: Multiple values are returned as a tuple

Variable Scope 🔍

Local Scope

Variables inside a function

def my_function():
x = 10 # Local
print(x)
my_function() # Works
print(x) # Error!

Global Scope

Variables outside functions

y = 20 # Global
def my_function():
print(y) # Can read
my_function() # Works
print(y) # Also works

Best Practice: Use local variables when possible. Keep functions self-contained!

Docstrings - Documentation 📚

Document your functions with docstrings (triple quotes)

Good Documentation:

def calculate_area(length, width):
"""
Calculate the area of a rectangle.
Args:
length: The length of the rectangle
width: The width of the rectangle
Returns:
The area of the rectangle
"""
return length * width

Good documentation helps others (and future you!) understand your code

Lambda Functions ⚡

Optional/Advanced: Small, anonymous functions for simple operations

Regular Function

def square(x):
return x ** 2
result = square(5)

Lambda Function

square = lambda x: x ** 2
result = square(5)

Common Use Cases:

# Sorting with lambda
students = [("Alice", 85), ("Bob", 92), ("Carol", 78)]
sorted_students = sorted(students, key=lambda x: x[1])

Real-World Example 🌍

Temperature Converter

def celsius_to_fahrenheit(celsius):
"""Convert Celsius to Fahrenheit."""
fahrenheit = (celsius * 9/5) + 32
return fahrenheit
def fahrenheit_to_celsius(fahrenheit):
"""Convert Fahrenheit to Celsius."""
celsius = (fahrenheit - 32) * 5/9
return celsius
# Usage
temp_c = 25
temp_f = celsius_to_fahrenheit(temp_c)
print(f"{temp_c}°C = {temp_f}°F") # 25°C = 77.0°F
