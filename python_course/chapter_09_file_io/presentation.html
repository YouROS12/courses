File I/O - Reading and Writing Files

Making Your Data Permanent

Why Work with Files?

Files give your programs memory - data that survives after the program ends!

Without Files:

  • ❌ Data lost when program closes
  • ❌ Can't save user settings
  • ❌ No way to share data
  • ❌ Must re-enter everything

With Files:

  • ✓ Data persists forever
  • ✓ Save and load settings
  • ✓ Share with other programs
  • ✓ Build real applications!

Real-World Examples:

📝 Note-taking apps
📊 Saving game progress
📇 Contact managers
📈 Data analysis

Opening and Closing Files

Basic File Operations:

# Opening a file
file = open("myfile.txt", "r") # "r" = read mode
# Do something with the file
content = file.read()
# Always close when done!
file.close()

File Modes:

"r" - Read (default)
"w" - Write (overwrites!)
"a" - Append (adds to end)
"r+" - Read and Write

Important: Always close files when done! But there's a better way...

Reading Files

read() - Read Entire File:

file = open("story.txt", "r")
content = file.read() # All text as one string
file.close()

readline() - Read One Line:

file = open("data.txt", "r")
line1 = file.readline() # First line
line2 = file.readline() # Second line
file.close()

readlines() - Read All Lines as List:

file = open("names.txt", "r")
lines = file.readlines() # List of lines
file.close()

Writing and Appending to Files

Write Mode ("w") - Overwrites File:

file = open("output.txt", "w")
file.write("Hello, World!\n")
file.write("Python is awesome!")
file.close()

Append Mode ("a") - Adds to End:

file = open("log.txt", "a")
file.write("New log entry\n")
file.close() # Keeps existing content!

Warning: "w" mode erases the file! Use "a" to preserve content.

The 'with' Statement (Best Practice!)

The with statement automatically closes files - even if errors occur!

Old Way:

file = open("data.txt")
content = file.read()
file.close() # Must remember!
# If error occurs,
# file stays open!

Better Way:

with open("data.txt") as file:
content = file.read()
# Use file here
# File automatically
# closed here!

Always use 'with' when working with files!

Example:

with open("names.txt", "r") as file:
names = file.read()
print(names)

File Paths: Absolute vs Relative

Relative Path (from current folder):

# File in same folder
open("data.txt")
# File in subfolder
open("files/data.txt")
# File in parent folder
open("../data.txt")

Absolute Path (complete location):

# Windows
open("C:/Users/Name/Documents/data.txt")
# Mac/Linux
open("/home/user/documents/data.txt")

Tip: Use relative paths for portable code!

Working with CSV Files

CSV (Comma-Separated Values) - perfect for spreadsheet data!

Sample CSV File (students.csv):

Name,Age,Grade
Alice,20,A
Bob,19,B
Carol,21,A

Reading CSV:

import csv
with open("data.csv") as f:
reader = csv.reader(f)
for row in reader:
print(row)

Writing CSV:

import csv
with open("out.csv", "w") as f:
writer = csv.writer(f)
writer.writerow([...])
writer.writerow([...])

Working with JSON Files

JSON - perfect for storing dictionaries and structured data!

Sample JSON (config.json):

{
"username": "alice",
"theme": "dark",
"score": 1250
}

Reading JSON:

import json
with open("data.json") as f:
data = json.load(f)
print(data["username"])

Writing JSON:

import json
data = {"name": "Alice"}
with open("out.json", "w") as f:
json.dump(data, f)

Using datetime for Timestamps

Add timestamps to your log files and data!

Getting Current Date/Time:

from datetime import datetime
now = datetime.now()
print(now) # 2024-11-19 14:30:25.123456
# Formatted timestamp
timestamp = now.strftime("%Y-%m-%d %H:%M:%S")
print(timestamp) # 2024-11-19 14:30:25

Writing Timestamped Logs:

from datetime import datetime
with open("log.txt", "a") as file:
timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
file.write(f"{timestamp} - User logged in\n")

File Error Handling

Files can cause errors - be prepared!

Common File Errors:

  • ❌ FileNotFoundError - File doesn't exist
  • ❌ PermissionError - No permission to access
  • ❌ IsADirectoryError - Tried to open a folder

Basic Error Handling:

try:
with open("data.txt") as file:
content = file.read()
except FileNotFoundError:
print("File not found!")
