# Problèmes de Pratique Supplémentaires

Ce répertoire contient des problèmes de pratique supplémentaires pour renforcer vos compétences en Python. Utilisez-les pour :

- Pratiquer après avoir terminé chaque chapitre
- Vous préparer aux quiz
- Vous défier avec des problèmes plus difficiles
- Gagner en confiance avant le projet capstone

## Ensembles de Pratique Disponibles

| Fichier | Sujets | Difficulté | Problèmes |
|------|--------|------------|----------|
| [basics_practice.md](basics_practice.md) | Variables, types de données, opérateurs, chaînes | Débutant | 15 |
| [control_flow_practice.md](control_flow_practice.md) | Instructions if, boucles, logique | Débutant-Intermédiaire | 20 |

| [files_practice.md](files_practice.md) | Entrée/sortie de fichiers, CSV, JSON | Intermédiaire | 10 |
| [mixed_challenges.md](mixed_challenges.md) | Sujets mixtes | Intermédiaire-Avancé | 10 |

## Comment Utiliser

1. **Choisissez un ensemble de pratique** en fonction de ce que vous voulez pratiquer
2. **Essayez de résoudre les problèmes** sans regarder les indices d'abord
3. **Utilisez les indices** si vous êtes bloqué
4. **Vérifiez les solutions** après avoir essayé (solutions à la fin de chaque fichier)
5. **Expérimentez** avec différentes approches

## Niveaux de Difficulté

- **Débutant** : Application directe des concepts
- **Intermédiaire** : Nécessite de combiner plusieurs concepts
- **Avancé** : Problèmes difficiles nécessitant des solutions créatives

## Conseils pour la Pratique

- **Commencez petit** : Si vous êtes bloqué, résolvez d'abord une version plus simple
- **Testez fréquemment** : Exécutez votre code souvent pour détecter les erreurs tôt
- **Lisez attentivement les erreurs** : Elles vous disent généralement ce qui ne va pas
- **N'abandonnez pas** : Lutter fait partie de l'apprentissage
- **Essayez différentes approches** : Il y a souvent plus d'une solution
