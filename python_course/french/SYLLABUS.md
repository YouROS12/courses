# Cours de Programmation Python - Programme Complet

## Informations sur le Cours

**Titre du Cours** : Programmation Python pour Débutants
**Niveau** : Débutant à Intermédiaire
**Prérequis** : Aucun - conçu pour les débutants complets
**Durée Totale** : 25-35 heures (à votre rythme)
**Format** : Présentations vidéo, exercices pratiques, quiz, projet final

## Résultats d'Apprentissage

À la fin de ce cours, vous serez capable de :

1. Écrire des programmes Python propres et fonctionnels à partir de zéro
2. Comprendre et appliquer les concepts fondamentaux de la programmation
3. Travailler avec diverses structures de données (listes, dictionnaires, ensembles, tuples)
4. Lire et écrire dans des fichiers (texte, CSV, JSON)
5. Gérer les erreurs avec élégance en utilisant la gestion des exceptions
6. Concevoir et implémenter des fonctions pour la réutilisabilité du code
7. Créer des applications du monde réel avec Python
8. Déboguer et dépanner efficacement le code Python
9. Appliquer les meilleures pratiques en programmation Python
10. Continuer à apprendre des sujets Python avancés de manière autonome

### Projet Final

**Durée** : 4-8 heures
**Format** : Choisissez 1 parmi 3 projets

#### Options de Projet

1. **Suivi des Dépenses Personnelles**
   - Suivre les revenus et dépenses
   - Catégoriser les transactions
   - Générer des rapports
   - Sauvegarder les données en JSON
   - Calculer les soldes et résumés

2. **Gestionnaire de Notes d'Étudiants**
   - Ajouter et gérer les dossiers d'étudiants
   - Suivre les notes dans plusieurs matières
   - Calculer les moyennes et statistiques
   - Importer/exporter en CSV
   - Générer des bulletins de notes

3. **Gestionnaire de Contacts Simple**
   - Ajouter, modifier, supprimer des contacts
   - Rechercher des contacts
   - Catégoriser les contacts
   - Exporter en JSON ou CSV
   - Gérer la validation des données

#### Critères d'Évaluation du Projet

- **Fonctionnalité** (40%) : Fonctionne-t-il comme spécifié ?
- **Qualité du Code** (30%) : Le code est-il propre et organisé ?
- **Gestion des Erreurs** (15%) : Gère-t-il les erreurs avec élégance ?
- **Expérience Utilisateur** (15%) : Est-il facile à utiliser ?

**Semaine 1** :

- Mar : Chapitre 2
