# Cours de Programmation Python pour Débutants

Bienvenue dans le **Cours Complet de Programmation Python** ! Ce cours complet et pratique est conçu pour vous faire passer de débutant absolu à programmeur Python confiant.

## 📚 Aperçu du Cours

Ce cours contient **10 chapitres structurés**, **6 quiz progressifs** et un **projet final complet** qui vous enseigneront tout ce dont vous avez besoin pour commencer à programmer en Python. Aucune expérience de programmation préalable n'est requise !

### Ce Que Vous Apprendrez

- **Fondamentaux de la Programmation** : Variables, types de données, opérateurs et entrées/sorties de base
- **Flux de Contrôle** : Conditions, boucles et opérations logiques
- **Structures de Données** : Listes, dictionnaires, tuples et ensembles
- **Fonctions** : Écriture de code réutilisable et modulaire
- **Opérations sur Fichiers** : Lecture et écriture de fichiers (texte, CSV, JSON)
- **Gestion des Erreurs** : Écriture de code robuste avec gestion des exceptions
- **Projets Concrets** : Création d'applications pratiques de zéro

## 🚀 Commencer

### Démarrage Rapide (Recommandé - Aucune Installation Requise !)

1. **Ouvrez le cahier de pratique de n'importe quel chapitre** (fichier `.ipynb`)
2. **Cliquez sur "Ouvrir dans Colab"** en haut du cahier
3. **Commencez à coder immédiatement** dans votre navigateur !

Tous les exercices sont conçus pour fonctionner dans Google Colab sans aucune configuration.

### Installation Locale

Si vous préférez travailler localement :

```bash
# Clonez ou téléchargez ce dépôt
git clone <url-du-dépôt>

# Installez les paquets requis
pip install -r requirements.txt

# Ouvrez les cahiers Jupyter
jupyter notebook
```

📖 **Instructions de Configuration Détaillées** : Voir [GETTING_STARTED.md](GETTING_STARTED.md)

## 📅 Parcours d'Étude Recommandé

### Apprentissage à Votre Rythme

- **Parcours Débutant** : 2-3 chapitres par semaine (10-12 semaines au total)
- **Parcours Intensif** : 1 chapitre par jour (2 semaines au total)
- **Parcours Décontracté** : 1 chapitre par semaine (10 semaines au total)

### Routine d'Étude

1. **Regardez/Lisez la Présentation** (30-45 minutes)
2. **Complétez les Exercices de Pratique** (60-90 minutes)
3. **Passez le Quiz** après chaque 2 chapitres (30 minutes)
4. **Construisez le Projet Final** (4-6 heures)
