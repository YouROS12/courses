### Projet 1 : Suivi des Dépenses Personnelles

**Description :**
Créez une application en ligne de commande qui aide les utilisateurs à suivre leurs dépenses personnelles, catégoriser leurs dépenses et générer des rapports financiers.

**Ce que vous allez construire :**
- Ajouter et enregistrer des dépenses avec montant, catégorie et description
- Voir toutes les dépenses ou filtrer par catégorie
- Calculer les dépenses totales et par catégorie
- Sauvegarder et charger les données de dépenses depuis des fichiers
- Générer des rapports mensuels
- Gérer les entrées invalides avec élégance

**Concepts Couverts :**
- ✅ Variables et types de données (Chapitres 1-2)
- ✅ Entrée/sortie utilisateur (Chapitre 2)
- ✅ Conditions pour validation et options de menu (Chapitre 3)
- ✅ Boucles pour système de menu et itération de données (Chapitre 4)
- ✅ Listes pour stocker plusieurs dépenses (Chapitre 5)
- ✅ Dictionnaires pour enregistrements de dépenses et catégories (Chapitre 6)
- ✅ Fonctions pour organisation du code (Chapitre 7)
- ✅ Tuples pour données immuables (date, heure) (Chapitre 8)
- ✅ Ensembles pour catégories uniques (Chapitre 8)
- ✅ E/S de fichiers avec JSON pour persistance des données (Chapitre 9)
- ✅ Gestion des erreurs pour fonctionnement robuste (Chapitre 10)

**Fonctionnalités Exemple :**
```
1. Ajouter une Dépense
2. Voir Toutes les Dépenses
3. Voir les Dépenses par Catégorie
4. Calculer les Dépenses Totales
5. Résumé par Catégorie
6. Rapport Mensuel
7. Quitter (Sauvegarde Automatique)
```

## Conseils pour Réussir

### Avant de Commencer :
1. **Lisez tout** - Comprenez le projet complet avant de coder
2. **Choisissez judicieusement** - Choisissez le projet qui vous intéresse le plus
3. **Planifiez votre temps** - Cela prendra 2-3 semaines de travail régulier
4. **Configurez votre environnement** - Assurez-vous que Python et Jupyter sont prêts

### Pendant la Construction :
1. **Commencez petit** - Construisez une fonctionnalité à la fois
2. **Testez fréquemment** - Testez chaque fonction avant de continuer
3. **Utilisez des commentaires** - Expliquez votre code à votre futur vous-même
4. **Sauvegardez souvent** - Utilisez le contrôle de version ou sauvegardez des copies
5. **Demandez de l'aide** - C'est normal de chercher ou de poser des questions
6. **Faites des pauses** - N'essayez pas de tout faire en une seule fois

### Meilleures Pratiques :
1. **Noms de fonctions** - Utilisez des noms descriptifs (ex: `add_expense` pas `ae`)
2. **Noms de variables** - Clairs et significatifs (ex: `total_amount` pas `ta`)
3. **Organisation du code** - Regroupez les fonctions connexes ensemble
4. **Messages d'erreur** - Rendez-les utiles et conviviaux
5. **Retour utilisateur** - Affichez des messages de confirmation pour les actions
6. **Validation des entrées** - Validez toujours les entrées utilisateur avant traitement

### Tester Votre Projet :
1. **Chemin heureux** - Testez quand tout fonctionne correctement
2. **Cas limites** - Testez avec des données vides, des valeurs nulles, etc.
3. **Entrée invalide** - Testez avec de mauvais types de données, nombres négatifs
4. **Opérations de fichiers** - Testez quand les fichiers n'existent pas
5. **Grands ensembles de données** - Testez avec de nombreux enregistrements

### Conseils de Débogage :
1. **Instructions print** - Utilisez print() pour voir ce qui se passe
2. **Vérifiez les types de données** - Assurez-vous que les variables sont ce que vous attendez
3. **Lisez les messages d'erreur** - Ils vous disent exactement ce qui ne va pas
4. **Utilisez try-except** - Capturez les erreurs et gérez-les avec élégance
5. **Décomposez les problèmes** - Isolez le problème à une fonction
