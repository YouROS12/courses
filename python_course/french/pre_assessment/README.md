# Test de Pré-évaluation

Avant de commencer le cours, passez cette pré-évaluation pour :
- Évaluer vos connaissances actuelles en Python
- Identifier les chapitres que vous pourriez sauter
- Établir une référence pour mesurer vos progrès

## Instructions

1. **N'étudiez pas à l'avance** - cela évalue ce que vous savez déjà
2. **Soyez honnête** - il est normal de ne pas savoir certaines choses !
3. **Ne cherchez pas les réponses** - devinez si vous n'êtes pas sûr
4. **Chronométrez-vous** - essayez de terminer en 30 minutes
5. **Vérifiez vos réponses** après avoir terminé

## Guide de Notation

Après avoir terminé le test, vérifiez le corrigé et comptez vos réponses correctes :

### Interprétation des Scores

**0-5 réponses correctes (0-25%)**
- **Recommandation** : Commencez par le Chapitre 1
- **Parcours** : Complétez tous les chapitres de manière séquentielle
- **Vous apprendrez** : Tout depuis le début
- **Parfait pour** : Les débutants complets

**6-10 réponses correctes (30-50%)**
- **Recommandation** : Commencez par le Chapitre 1, mais avancez plus rapidement
- **Parcours** : Parcourez rapidement les sujets familiers, concentrez-vous sur les nouveaux
- **Vous apprendrez** : Les bonnes pratiques Python et comblerez les lacunes de connaissances
- **Parfait pour** : Une certaine exposition à la programmation

**11-15 réponses correctes (55-75%)**
- **Recommandation** : Commencez par le Chapitre 3 ou 5
- **Parcours** : Révisez rapidement les bases, concentrez-vous sur les sujets intermédiaires
- **Vous apprendrez** : Structures de données, fonctions, gestion de fichiers
- **Parfait pour** : Connaissances de base en Python

**16-20 réponses correctes (80-100%)**
- **Recommandation** : Commencez par le Chapitre 7 ou suivez un cours avancé
- **Parcours** : Passez directement aux fonctions et sujets avancés
- **Vous apprendrez** : Concepts avancés, meilleures pratiques
- **Parfait pour** : Connaissances intermédiaires en Python

## Que Faire Ensuite

En fonction de votre score :

1. **Révisez les questions manquées** - identifiez les domaines faibles
2. **Lisez le syllabus** - comprenez ce que vous allez apprendre
3. **Commencez au chapitre recommandé** - ne sautez pas trop
4. **Suivez vos progrès** - repassez le test après avoir terminé le cours

## Conseils pour Passer le Test

- **Lisez attentivement** - les questions peuvent être délicates
- **Montrez votre travail** - écrivez du code pour les questions de programmation
- **Sautez et revenez** - ne restez pas bloqué sur les questions difficiles
- **Restez calme** - c'est juste pour vous aider, pas pour vous juger
