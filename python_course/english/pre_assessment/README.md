# Pre-Assessment Test

Before starting the course, take this pre-assessment to:
- Gauge your current Python knowledge
- Identify which chapters you might skip
- Set a baseline to measure your progress

## Instructions

1. **Don't study beforehand** - this assesses what you already know
2. **Be honest** - it's okay not to know things!
3. **Don't look up answers** - guess if you're unsure
4. **Time yourself** - try to complete in 30 minutes
5. **Check your answers** after completing

## Scoring Guide

After completing the test, check the answer key and count your correct answers:

### Score Interpretation

**0-5 correct (0-25%)**
- **Recommendation**: Start from Chapter 1
- **Path**: Complete all chapters sequentially
- **You'll learn**: Everything from the ground up
- **Perfect for**: Complete beginners

**6-10 correct (30-50%)**
- **Recommendation**: Start from Chapter 1, but move faster
- **Path**: Skim familiar topics, focus on new ones
- **You'll learn**: Proper Python practices and fill knowledge gaps
- **Perfect for**: Some programming exposure

**11-15 correct (55-75%)**
- **Recommendation**: Start from Chapter 3 or 5
- **Path**: Review basics quickly, focus on intermediate topics
- **You'll learn**: Data structures, functions, file handling
- **Perfect for**: Basic Python knowledge

**16-20 correct (80-100%)**
- **Recommendation**: Start from Chapter 7 or take advanced course
- **Path**: Skip to functions and advanced topics
- **You'll learn**: Advanced concepts, best practices
- **Perfect for**: Intermediate Python knowledge

## What to Do Next

Based on your score:

1. **Review missed questions** - identify weak areas
2. **Read the syllabus** - understand what you'll learn
3. **Start at recommended chapter** - don't skip too much
4. **Track progress** - retake after completing course

## Tips for Taking the Test

- **Read carefully** - questions may be tricky
- **Show your work** - write code for programming questions
- **Skip and return** - don't get stuck on hard questions
- **Stay calm** - it's just to help you, not to judge you
