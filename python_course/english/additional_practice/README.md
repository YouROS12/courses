# Additional Practice Problems

This directory contains extra practice problems to reinforce your Python skills. Use these to:

- Practice after completing each chapter
- Prepare for quizzes
- Challenge yourself with harder problems
- Build confidence before the capstone project

## Available Practice Sets

| File | Topics | Difficulty | Problems |
|------|--------|------------|----------|
| [basics_practice.md](basics_practice.md) | Variables, data types, operators, strings | Beginner | 15 |
| [control_flow_practice.md](control_flow_practice.md) | If statements, loops, logic | Beginner-Intermediate | 20 |
| [data_structures_practice.md](data_structures_practice.md) | Lists, dictionaries, tuples, sets | Intermediate | 20 |
| [functions_practice.md](functions_practice.md) | Functions, scope, recursion | Intermediate | 15 |
| [files_practice.md](files_practice.md) | File I/O, CSV, JSON | Intermediate | 10 |
| [mixed_challenges.md](mixed_challenges.md) | Mixed topics | Intermediate-Advanced | 10 |

## How to Use

1. **Choose a practice set** based on what you want to practice
2. **Try solving problems** without looking at hints first
3. **Use hints** if you're stuck
4. **Check solutions** after attempting (solutions at end of each file)
5. **Experiment** with different approaches

## Difficulty Levels

- **Beginner**: Straightforward application of concepts
- **Intermediate**: Requires combining multiple concepts
- **Advanced**: Challenging problems requiring creative solutions

## Tips for Practice

- **Start small**: If stuck, solve a simpler version first
- **Test frequently**: Run your code often to catch errors early
- **Read errors carefully**: They usually tell you what's wrong
- **Don't give up**: Struggling is part of learning
- **Try different approaches**: There's often more than one solution
