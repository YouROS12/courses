Dictionaries - Key-Value Pairs

Storing Connected Data

What Are Dictionaries? 📖

A dictionary stores data as key-value pairs - like a real dictionary!

Real Dictionary

Word: Python
Definition: A programming language
Word = Key, Definition = Value

Python Dictionary

student = {
"name": "Alice",
"age": 20,
"grade": "A"
}

Each key maps to a specific value!

Why Use Dictionaries? 🤔

🔗

Connect Related Data

Store attributes that belong together

🎯

Fast Lookup

Find values instantly using keys

📝

Meaningful Names

Use descriptive keys instead of indices

🔄

Flexible

Add, modify, or remove data easily

Real-world examples: Contact information, product details, settings, user profiles

Creating Dictionaries ✨

Empty Dictionary

empty = {}

empty = dict()

Dictionary with Data

person = {
"name": "Ahmed",

}

Different Value Types

student = {
"name": "Sarah", # String
"age": 20, # Integer
"gpa": 3.8, # Float
"enrolled": True # Boolean
}

Accessing Values 🔍

Use keys (not indices) to access values

Square Bracket Notation

student = {"name": "Ali", "age": 22, "major": "CS"}
print(student["name"]) → "Ali"
print(student["age"]) → 22
print(student["major"]) → "CS"

get() Method (Safer)

print(student.get("name")) → "Ali"
print(student.get("email")) → None # No error!
print(student.get("email", "Not found")) → "Not found"

💡 Tip: Use get() to avoid errors when key might not exist

Modifying Dictionaries 🔧

Change Existing Value

person = {"name": "John", "age": 25}
person["age"] = 26
# → {"name": "John", "age": 26}

Add New Key-Value Pair

person = {"name": "John", "age": 25}
person["city"] = "New York"
# → {"name": "John", "age": 25, "city": "New York"}

Remove Items

del person["age"] # Remove specific key
removed = person.pop("city") # Remove & return value
person.clear() # Remove all items

Dictionary Methods 🛠️

keys() - Get all keys

student.keys() → dict_keys(['name', 'age', 'grade'])

values() - Get all values

student.values() → dict_values(['Alice', 20, 'A'])

items() - Get key-value pairs

student.items() → dict_items([('name', 'Alice'), ('age', 20), ('grade', 'A')])

update() - Add multiple items

student.update({"city": "Boston", "major": "CS"})

pop() - Remove and return value

grade = student.pop("grade") → Returns "A" and removes it

Iterating Through Dictionaries 🔄

Loop Through Keys

for key in student:
print(key)

Loop Through Values

for value in student.values():
print(value)

Loop Through Key-Value Pairs (Best!)

for key, value in student.items():
print(f"{key}: {value}")

Dictionary vs List ⚖️

Lists 📋

✓ Ordered collection
✓ Access by index (position)
✓ Use for sequences
✓ Allow duplicates
students = [
"Ali", "Sara",
"Ahmed"
]

Dictionaries 📖

✓ Key-value pairs
✓ Access by key (name)
✓ Use for related data
✓ Keys must be unique
student = {
"name": "Ali",
"age": 20
}

Use Lists: for ordered items | Use Dictionaries: for labeled data

Real-World: Contact Book 📱

# Contact book with phone numbers
contacts = {
"Alice": "555-1234",
"Bob": "555-5678",
"Carol": "555-9012"
}
# Look up a number
name = input("Enter name: ")
if name in contacts:
phone = contacts[name]
print(f"{name}'s number: {phone}")
else:
print("Contact not found!")
# Add new contact
contacts["David"] = "555-3456"
# Display all contacts
for name, phone in contacts.items():
print(f"{name}: {phone}")

Nested Dictionaries 🎁

Dictionaries can contain other dictionaries!

Student Records Example

students = {
"student1": {
"name": "Alice",
"age": 20,
"grades": {"math": 90, "english": 85}
},
"student2": {
"name": "Bob",
"age": 21,
"grades": {"math": 88, "english": 92}
}
}

Accessing Nested Data

print(students["student1"]["name"]) → "Alice"
