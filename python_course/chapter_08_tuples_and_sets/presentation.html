Tuples and Sets - More Data Structures

Specialized Tools for Special Jobs

What Are Tuples?

Tuples are like lists, but immutable (cannot be changed)

Lists

my_list = [1, 2, 3]
my_list[0] = 10 # OK
# Can modify!

Tuples

my_tuple = (1, 2, 3)
my_tuple[0] = 10 # Error!
# Cannot modify!

Key Difference: Use parentheses ( ) for tuples, brackets [ ] for lists

Why Use Tuples?

  • ✓ Protect data from accidental changes
  • ✓ Faster than lists
  • ✓ Can be used as dictionary keys

Creating and Accessing Tuples

Creating Tuples:

# Empty tuple
empty = ()
# Single element (note the comma!)
single = (5,)
# Multiple elements
coordinates = (10, 20)
colors = ("red", "green", "blue")

Accessing Elements (Like Lists):

point = (10, 20, 30)
print(point[0]) # 10
print(point[-1]) # 30
print(point[1:3]) # (20, 30)

Tuple Unpacking

Easily assign tuple values to multiple variables at once!

Basic Unpacking:

coordinates = (10, 20)
# Unpack into variables
x, y = coordinates
print(f"x = {x}, y = {y}") # x = 10, y = 20

Swapping Variables:

a = 5
b = 10
# Swap values in one line!
a, b = b, a
print(f"a = {a}, b = {b}") # a = 10, b = 5

Tuples vs Lists: When to Use Each?

Use Tuples When:

  • 📍 Data shouldn't change
    (coordinates, RGB colors)
  • 🔑 Need dictionary keys
    (lists can't be keys)
  • ⚡ Want better performance
    (tuples are faster)
  • 📦 Returning multiple values
    from functions

Use Lists When:

  • ✏️ Data needs to change
    (shopping cart, to-do list)
  • ➕ Adding/removing items
    (append, remove, pop)
  • 🔄 Sorting or reversing
    (list.sort(), list.reverse())
  • 📊 Collection of similar items
    (scores, names, prices)

What Are Sets?

Sets are collections of unique elements (no duplicates!)

Key Features:

✓ No duplicate values

✓ Unordered (no indexing)

✓ Fast membership testing

✓ Mathematical set operations

Example:

# List with duplicates
numbers = [1, 2, 2, 3, 3, 3]
# Set automatically removes duplicates
unique = set(numbers)
print(unique) # {1, 2, 3}

Creating and Using Sets

Creating Sets:

# Using curly braces
fruits = {"apple", "banana", "orange"}
# Using set() function
numbers = set([1, 2, 3, 2, 1]) # {1, 2, 3}
# Empty set (must use set(), not {})
empty = set() # {} creates empty dict!

Adding and Removing:

colors = {"red", "blue"}
colors.add("green") # Add one item
colors.remove("red") # Remove item
colors.discard("yellow") # Remove (no error if missing)

Set Operations

Union (|) - Combine All Elements:

set1 = {1, 2, 3}
set2 = {3, 4, 5}
print(set1 | set2) # {1, 2, 3, 4, 5}

Intersection (&) - Common Elements:

set1 = {1, 2, 3}
set2 = {3, 4, 5}
print(set1 & set2) # {3}

Difference (-) - Elements Only in First:

set1 = {1, 2, 3}
set2 = {3, 4, 5}
print(set1 - set2) # {1, 2}

Practical Use: Removing Duplicates

Sets are perfect for removing duplicates from lists!

The Problem:

scores = [85, 92, 85, 78, 92, 88]
# Too many duplicates!

The Solution:

# Convert to set, then back to list
unique_scores = list(set(scores))
print(unique_scores) # [85, 92, 78, 88]

Sets automatically eliminate duplicates - super handy!

When to Use Sets?

✓ Remove Duplicates

Clean up lists with repeated items

✓ Fast Membership Testing

Check if item exists (faster than lists)

✓ Set Operations

Find common or unique elements

✓ Unique Collections

Store items that must be unique

Remember: Sets are unordered - you can't access by index!
