Interactive Programs & Type Conversion

Getting User Input 💬

The input() function lets users interact with your program!

Basic Syntax:

variable = input("Prompt message")

Example:

name = input("What is your name? ")
print("Hello,", name)

Note: input() always returns a string (text)

The Input Problem 🤔

❌ This Won't Work:

age = input("How old are you? ")
next_year = age + 1
TypeError: can only concatenate str to str

What input() gives you:

A string (text)

"25"

What you might need:

A number

25

Solution: Type Conversion! 🔄

Type Conversion 🔄

Converting data from one type to another

int()

Convert to integer

int("25") → 25
int(3.9) → 3

float()

Convert to decimal

float("3.14") → 3.14
float(5) → 5.0

str()

Convert to string

str(25) → "25"
str(3.14) → "3.14"

✓ Now This Works:

age = input("How old are you? ")
age = int(age) # Convert to integer
next_year = age + 1
print("Next year you'll be", next_year)

Conversion Shortcut 🚀

You can combine input() with type conversion in one line!

Long Way:

age = input("Age? ")
age = int(age)

Short Way:

age = int(input("Age? "))

More Examples:

price = float(input("Enter price: "))
quantity = int(input("Enter quantity: "))
total = price * quantity
print("Total:", total)

String Operations ✂️

Concatenation (Joining)

first = "Hello"
second = "World"
result = first + " " + second
→ "Hello World"

Useful String Methods

.upper() → UPPERCASE
"hello".upper() → "HELLO"
.lower() → lowercase
"HELLO".lower() → "hello"
.strip() → remove spaces
" hi ".strip() → "hi"
.replace() → swap text
"cat".replace("c", "b") → "bat"

String Length

len("Python") → 6

Comments in Code 📝

Comments are notes for humans - Python ignores them!

Single-Line Comments:

# This is a comment
price = 99.99 # Price in dollars

Multi-Line Comments:

"""
This is a longer comment
that spans multiple lines
"""

✓ Good Comments:

Explain WHY, not WHAT

Use Comments To:

Document complex logic

Understanding Errors 🐛

Errors are normal! They help you learn and fix problems.

ValueError

Trying to convert invalid text to number

int("hello") → ValueError

TypeError

Mixing incompatible types

"5" + 5 → TypeError

SyntaxError

Invalid Python syntax

print("hello" → SyntaxError (missing closing parenthesis)

💡 Tip: Read error messages carefully - they tell you what went wrong!

Interactive Program Example 🎮

Personal Calculator

# Get user information
name = input("What's your name? ")
age = int(input("How old are you? "))
# Calculate years until retirement (assume 65)
years_left = 65 - age
# Format name nicely
formatted_name = name.upper()
# Display personalized message
message = f"Hello {formatted_name}! You have {years_left} years until retirement."
print(message)
